# 接口与模型调用监控

应用沿用 Actuator、Micrometer 和 Prometheus，在 `/actuator/prometheus` 导出指标。接口耗时已启用直方图，模型调用耗时与流式首帧耗时也导出直方图，支持跨实例计算 P95/P99。

## 模型指标

以下指标覆盖 DeepSeek、通义千问，以及后续继承通用 OpenAI 兼容适配基类的供应商。原有 mock 指标保持不变，stub 不产生真实下游调用。

| Prometheus 名称 | 含义 |
| --- | --- |
| `gateway_provider_started_total` | 下游调用开始次数，可计算进入 QPS |
| `gateway_provider_requests_total` | 已结束调用次数，包含成功、失败和取消 |
| `gateway_provider_inflight` | 当前在途调用数 |
| `gateway_provider_duration_seconds_count/sum/bucket` | 调用次数、总耗时和耗时分布 |
| `gateway_provider_first_frame_seconds_count/sum/bucket` | 流式首帧耗时 |

标签为 `application`、`provider`、`model`、`stream`；结束计数和总耗时增加 `outcome=success/error/cancelled`。模型标签仅使用配置中的名称，其他输入归为 `unknown`，避免任意输入产生大量时间序列。

耗时从订阅开始，直到响应读取结束，包含网络等待和流式生成时间，不包含网关历史消息读取、消息保存。首帧是上游第一条 SSE 数据事件，可能仅包含角色信息，不等于首次有效回答内容，也不代表客户端已经收到。

流式响应收到 `[DONE]` 后，由网关主动停止订阅，计为成功；没有 `[DONE]` 就自然结束计为失败；客户端提前取消计为取消。计数按订阅统计，每次重新订阅属于新的调用。

## Grafana 查询

接口 P95（单位：秒）：

```promql
histogram_quantile(0.95,
  sum by (le, uri) (rate(http_server_requests_seconds_bucket{
    application="ai-gateway", uri!~"/actuator.*"
  }[5m]))
)
```

将 `0.95` 改为 `0.99` 即为 P99。

下游进入 QPS：

```promql
sum by (provider, model, stream) (
  rate(gateway_provider_started_total{application="ai-gateway"}[1m])
)
```

当前查询窗口内的调用次数（窗口根据看板时间范围变化，短于采集间隔的调用无法精确还原）：

```promql
sum by (provider, model, stream) (
  increase(gateway_provider_started_total{application="ai-gateway"}[$__range])
)
```

已结束调用次数按结果分类：

```promql
sum by (provider, model, stream, outcome) (
  increase(gateway_provider_requests_total{application="ai-gateway"}[$__range])
)
```

平均下游响应时间（单位：秒，包含所有结束结果）：

```promql
sum by (provider, model, stream) (rate(gateway_provider_duration_seconds_sum{application="ai-gateway"}[5m]))
/
sum by (provider, model, stream) (rate(gateway_provider_duration_seconds_count{application="ai-gateway"}[5m]))
```

成功调用 P95（单位：秒）：

```promql
histogram_quantile(0.95,
  sum by (le, provider, model, stream) (
    rate(gateway_provider_duration_seconds_bucket{application="ai-gateway", outcome="success"}[5m])
  )
)
```

流式首帧 P95（单位：秒）：

```promql
histogram_quantile(0.95,
  sum by (le, provider, model) (
    rate(gateway_provider_first_frame_seconds_bucket{application="ai-gateway"}[5m])
  )
)
```

当前下游并发数：

```promql
sum by (provider, model, stream) (gateway_provider_inflight{application="ai-gateway"})
```

计数器在应用重启时归零，历史统计使用 `rate` 或 `increase`。没有实际调用时，对应计数和直方图尚未创建；低流量窗口可能没有可用的分位数或均值。流式和非流式应分别展示，避免长连接影响普通响应耗时判断。

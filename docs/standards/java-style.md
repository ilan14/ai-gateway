## Java代码风格规范

### 基本顺序
1. 静态常量（static final）。
2. 其他静态字段及相关静态初始化逻辑。
3. 实例字段：依赖、配置、运行时状态。
4. 构造方法。
5. 对外暴露的 public 方法及接口实现。
6. protected、包级可见方法。
7. private 辅助方法。
8. 内部类、枚举和 record。

### 方法组织原则
- 对外入口方法优先，按业务功能分组。
- 同一业务流程的辅助方法尽量就近排列。
- 重载方法相邻排列。
- 不强制按方法名字母顺序排序。
- 不因排序破坏初始化依赖或可读性。
- 类职责过多时优先考虑拆分。

### AI 编程约束
- Implementer 新增成员时遵循以上规则。
- 修改已有类时保持一致的组织方式。
- Reviewer 检查明显的成员组织混乱。
- 避免无关的大规模成员重排。
- 纯排序修改尽量与业务变更分开提交。
